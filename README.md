# F1 2023 Race Strategy Analysis

## Question
Is qualifying position or pit stop strategy a stronger predictor of race finishing position in F1?

## Key Finding
Grid position (r = 0.661) significantly outperforms pit stop count (r = -0.005) as a predictor of race finishing position. Where you start matters far more than how many times you stop.

## Dataset
Live data pulled from the [Jolpica F1 API](https://api.jolpi.ca/) covering all 22 races of the 2023 F1 season — race results, qualifying positions, and pit stop data.

## Tools
- Python (pandas, matplotlib, numpy)
- Tableau (visualisations)
- REST API (data collection)
